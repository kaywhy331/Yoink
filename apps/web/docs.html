Action and status guide

How signals become bounded Chrome actions, where user review is required, and what each visible status means.

Action flow

  1. A trusted signal identifies an exact retailer item.
  2. Yoink applies the saved price, seller, fulfillment, quantity, spend, and lane limits.
  3. The paired Chrome companion rechecks the live page and may click one exact Add control.
  4. Chrome proves an exact +1 cart delta before reporting Ready to check out.
  5. You complete checkout manually, then close the action as Got it or Missed it.

Status glossary

Queued
The exact bounded action is waiting for the paired Chrome companion.
Checking
Chrome is opening the store and revalidating the exact offer.
Ready to check out
The exact item was verified in the retailer cart. Checkout remains manual.
Needs you
Chrome cannot safely infer the result. Review the retailer cart or session.
Got it
You confirmed that manual checkout completed and supplied the amount charged for this item.
Missed it
You confirmed that checkout did not complete; no spend is recorded.

The dashboard’s “What these statuses mean” section is generated from the same status model used by the API.

Safety boundary

  • First-party seller only for guarded cart actions.
  • Exactly one item per guarded Add attempt.
  • Shipping is the default; Pickup runs only when explicitly selected and currently available.
  • Fresh DOM evidence is required at action time.
  • Checkout, payment, order submission, raffles, and challenge handling remain manual.
  • No CAPTCHA evasion, proxying, or request-mode cart mutation.

Troubleshooting

No cart-ready cue
Open Recent actions, confirm the companion is paired, and review any Needs-you action. The extension badge counts unreviewed cart handoffs.
Lane not qualified
Use the qualification candidate shown on the purchase plan, run Inspect product, then review the lane evidence in Connections.
Product did not qualify
Open View details or Diagnostics. Yoink preserves the decision reason without copying retailer page content or secrets.
